Setup

JellyShare puts the peers' titles into folders it owns, one per media type. Add each folder to your existing library of the same kind, so they appear next to your own movies, shows, music and audiobooks.

Reverse proxy on the same machine as Jellyfin? Make sure it sends an X-Forwarded-For header (nginx: proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;). The playback relay answers only loopback requests without proxy headers; a proxy that forwards requests without that header would make it reachable from outside.
